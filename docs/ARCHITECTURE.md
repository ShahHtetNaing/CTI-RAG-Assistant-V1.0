# CTI RAG separated architecture

## Design principle

The original `notebooks/CTI_RAG_Assistant.ipynb` is retained as the academic report and is not edited by this extraction stage. `backend/rag_engine.py` is generated by extracting the original notebook's dataset loading, indexing, model setup, prompts, retrieval, structured lookups, live ThreatCluster connector, email indicators, citations and `process_soc_query()` implementation.

Only the Gradio UI layer and Gradio progress object are omitted from the extracted engine. The processing function, model parameters, prompts, retrieval settings, data sources and response rules are preserved from the selected notebook source.

## Runtime

- GitHub: stores notebook, backend and frontend source.
- Vercel: serves `vercel-frontend/` as a static website.
- Google Colab: runs `backend/api.py` and the extracted RAG engine on the Colab GPU.
- Cloudflare Quick Tunnel: exposes the temporary Colab API over HTTPS.

## Start in Google Colab

1. Clone or upload this same GitHub repository into Colab at `/content/CTI-RAG-Assistant`.
2. Add `HF_TOKEN` and (optionally) `THREATCLUSTER_API_KEY` under Colab Secrets.
3. Open `backend/run_in_colab.py` and run its contents as a Colab cell (or paste it into a cell). Ensure the `%cd` path matches your clone directory.
4. Wait for the Cloudflare `trycloudflare.com` HTTPS URL.
5. Open your Vercel site and submit a question. When prompted, paste that URL. The browser remembers it locally.

## Deploy Vercel

For Vercel, keep the same GitHub repository and set Root Directory to `vercel-frontend`, Framework Preset to `Other`, Build Command blank, Output Directory `.` and Install Command blank. This only selects the frontend subfolder for deployment; it does not create a second repository. Vercel publishes only the frontend; the backend remains in the same GitHub repository but runs in Colab.

## Important limitations and security

- Colab must remain connected and the API/tunnel processes alive. The Quick Tunnel URL changes each time the session restarts.
- This is a temporary demonstration architecture, not production hosting.
- The API has no user authentication in this student-demo version. Anyone who knows the tunnel URL can call it and consume GPU resources. Do not share the URL publicly or process confidential emails.
- The tunnel is public HTTPS; CORS is configurable through `CTI_ALLOWED_ORIGINS`, but CORS is not authentication.
- Do not place Hugging Face or ThreatCluster secrets in frontend JavaScript or GitHub.
- Full dependency installation, model startup, GPU compatibility and a real inference request must be verified in the user's Colab runtime.
